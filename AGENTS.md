# Shopify Project Context

You are working on a Shopify ecommerce store for a small handmade/homemade jewelry business.

## Business Goal
The client currently sells handmade jewelry and wants to grow the business by selling online through Shopify.

The website should feel like a real jewelry brand: premium, elegant, warm, trustworthy, visually attractive, and focused on converting visitors into customers.

## Target Customers
Customers looking for:
- Handmade jewelry
- Everyday jewelry
- Gifts
- Jewelry for weddings and special occasions
- Unique/custom pieces

## Design Direction
- Premium and elegant
- Minimal but visually rich
- Strong focus on product photography
- Handmade/artisan feel
- Clean typography and spacing
- Mobile-first and fully responsive
- Smooth and intuitive shopping experience
- Avoid unnecessary animations or overly complicated UI
- Maintain visual consistency throughout the store

## Important Store Features
The store should support:
- Homepage
- Shop/collection pages
- Product pages
- Product search
- Filtering and sorting
- Cart
- Shopify checkout
- Wishlist
- Product reviews
- About/brand story
- Contact
- Shipping and returns information
- Gift/custom jewelry options where applicable

## Shopify Development Rules

This is an existing Shopify theme. Before making any changes:

1. Inspect the existing theme structure and understand how the current implementation works.
2. Reuse existing sections, snippets, blocks, settings and components whenever possible.
3. Do not unnecessarily rewrite existing code.
4. Do not remove existing functionality unless explicitly requested.
5. Do not modify the live/production theme directly.
6. Keep changes compatible with Shopify's theme architecture and Liquid.
7. Prefer Liquid, HTML, CSS and JavaScript already used by the theme.
8. Do not introduce unnecessary libraries or dependencies.
9. Keep the code clean, reusable, maintainable and performant.
10. Ensure every UI change works properly on desktop, tablet and mobile.
11. Preserve existing Shopify functionality such as cart, product forms, variants, sections and theme settings.
12. Do not hardcode values that should be configurable through Shopify theme settings.
13. Follow the existing project's naming conventions and coding style.

## Development Environment

The local project is:

`Jewellery-Ecommerce`

The Shopify CLI and Git are already configured.

The Shopify store has:
- `Jewellery-Ecommerce/main` → LIVE/production theme
- `Development` themes → development/testing


Never intentionally make changes directly to the live theme.

## AI Agent Rules

Before implementing a requested feature:

1. Inspect the relevant existing files.
2. Identify which files need to be changed.
3. Briefly explain what you plan to change.
4. Make the smallest appropriate changes.
5. Do not modify unrelated files.
6. Check for existing functionality before creating duplicate functionality.
7. After making changes, check for obvious Liquid, HTML, CSS and JavaScript errors.
8. Consider mobile responsiveness for every UI change.

If a request is ambiguous or could significantly affect existing functionality, ask for clarification before making the change.

## Main Priority

For every change, prioritize:

1. User experience
2. Mobile responsiveness
3. Visual consistency
4. Conversion/sales
5. Performance
6. Accessibility
7. Maintainable code

The final website should feel like a premium handmade jewelry brand rather than a generic Shopify template.
